# Ferry for Homebrew

[Ferry](https://github.com/lenajeremy/ferry) sends photos, videos and files between your phones and computers over Wi‑Fi, encrypted.

```sh
brew install lenajeremy/ferry/ferry              # Ferry for the terminal and browser (macOS and Linux)
brew services start ferry                        # …running from login; then open http://localhost:7070
brew install --cask lenajeremy/ferry/ferry-app   # the Mac app
```

These files are written by `packaging/homebrew.sh` in the Ferry repository, for each release.
